## Methodology

- GBrain full was run from the public `gbrain-evals` harness at the published pinned commit. Command: `BRAINBENCH_N=3 npx bun eval/runner/multi-adapter.ts --adapter=gbrain --json`.
- Running current `gbrain-evals@ef7794f` against its default `gbrain#master` dependency failed before completion with `AIConfigError: AI gateway is not configured`; the published pinned reproduction worked.
- AgentBay used current main at `d87bb71d05e9c744244b8857653fb6ba5aa00305`, `npm run eval -- run --corpus brainbench --eval-mode`, Voyage `voyage-3-lite`, default full hybrid/entity-graph settings, and the default vector-only ablation.
- The BrainBench corpus was converted from public `world-v1` JSON to AgentBay NDJSON locally. AgentBay entries included title, compiled truth, and timeline text. `_facts` were used only to build sealed expected IDs, matching GBrain's query builder; `_facts` relation edges were not passed into AgentBay ingestion.
- AgentBay rows are medians across three independent eval runs on fresh transient Postgres databases. Variance is reported as observed min-max range.
- GBrain's public harness emits P@5 and R@5 for this adapter. It does not emit R@10, MRR, or per-query latency p50/p95 in the published BrainBench runner, so those cells are intentionally left as `n/a` rather than inferred.

## Interpretation

AgentBay loses this head-to-head decisively. GBrain's graph-first BrainBench adapter returns nearly every gold page in the top five, while AgentBay's current full pipeline lands roughly one third of relevant pages in the top five. This is not a close benchmark: the P@5 gap is 38.3 percentage points on the corpus GBrain publishes for relational personal-knowledge retrieval.

The comparison also repeats the PR #235 failure mode. AgentBay vector-only is stronger than full hybrid on R@5, R@10, MRR, p50, and p95, while full hybrid is only +0.2pp ahead on median P@5. That small P@5 edge does not rescue the hypothesis; it is within run-to-run noise and sits far below the brief's +5pp public-scorecard gate.
